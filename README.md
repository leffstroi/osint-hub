# OSINT Hub

Образовательная платформа разведки по открытым источникам (OSINT): 16 направлений (GEOINT, спутники, IMINT, SOCMINT, Telegram и защита аккаунтов, ники, e-mail/телефон, инфраструктура, транспорт, блокчейн, даркнет, дорки, компании, криптография, OPSEC, обучение), 225 инструментов с проверенными ссылками и интерактивная лаборатория в браузере (дорки, ники, EXIF+карта, солнце/тени, кодировки и хэши, AES-256, классические шифры, лаунчеры).

**Сайт:** https://leffstroi.github.io/osint-hub/

Всё работает на стороне клиента. Только законные цели: без слежки, доксинга и атак на чужие аккаунты.

```bash
npm install && npm run dev
```
